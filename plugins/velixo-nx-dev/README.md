# Velixo plugin for Claude Code — v2026.11.85

Connects Claude Code to supported ERP systems through the Velixo MCP server, and carries the
`velixo-design` skill, which styles any dashboard or file built from Velixo results. Velixo's finance
skills (variance analysis, drill-downs, journal entries) are delivered separately as `.skill` files.

> Generated by `npm run build` in `Velixo-Intelligence-Plugins` on 2026-11-27 (bf13e32).
> Don't edit files here; edit `src/` in that repository and rebuild.

## Install

```
/plugin marketplace add VelixoSolutions/Velixo-Claude-Plugin
/plugin install velixo-nx-dev@velixo-plugins
```

Authentication to the MCP server is OAuth: Claude Code opens a browser on first use.

## What's inside

```
.claude-plugin/plugin.json, marketplace.json   plugin + single-plugin marketplace
.mcp.json                                       Velixo MCP server (https://nx-dev.velixo.com/mcp)
skills/velixo-design/                           Velixo's palette, logos and layout for dashboards and files
```

Because the server is bundled, Claude adds its own prefix to the tool names; the `.skill` files
refer to the bare names (`execute_query`, `tool_guidance`).

`tool_guidance` is a **mandatory first call** before any `prepare_*` or `execute_*`.

## Privacy

The plugin sends your requests to the Velixo MCP server, which reads and writes your ERP data. See
Velixo's privacy policy: [Privacy](https://velixo.com/privacy).
