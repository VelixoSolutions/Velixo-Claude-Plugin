# Velixo plugin for Claude Code — v2026.11.23

Connects Claude Code to supported ERP systems through the Velixo MCP server and adds Velixo's
finance skills and slash commands on top.

> Generated by `npm run build` in `Velixo-Intelligence-Plugins` on 2026-11-10 (38c1540).
> Don't edit files here; edit `src/` in that repository and rebuild.

## Install

```
/plugin marketplace add VelixoSolutions/Velixo-Claude-Plugin
/plugin install velixo-nx-staging@velixo-plugins
```

Authentication to the MCP server is OAuth: Claude Code opens a browser on first use.

## What's inside

```
.claude-plugin/plugin.json, marketplace.json   plugin + single-plugin marketplace
.mcp.json                                       Velixo MCP server (https://nx-staging.velixo.com/mcp)
skills/                                         `velixo-design` `velixo-flux-writer` `velixo-variance-analyzer` `velixo-account-drilldown` `velixo-journal-entry` 
commands/                                       `/flux` `/drilldown` `/journal-entry` 
```

Because the server is bundled, Claude adds its own prefix to the tool names; the skills and commands
refer to the bare names (`execute_query`, `tool_guidance`).

`tool_guidance` is a **mandatory first call** before any `prepare_*` or `execute_*`.

## Privacy

The plugin sends your requests to the Velixo MCP server, which reads and writes your ERP data. See
Velixo's privacy policy: [Privacy](https://velixo.com/privacy).
